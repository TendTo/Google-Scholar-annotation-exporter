将 Google 学术 PDF 阅读器中的批注（高亮和笔记）导出为 JSON、CSV、LaTeX、Markdown 或自定义格式。

主要功能：

导出当前页面中所选论文的批注，或自动逐页导出全部批注
支持 JSON、CSV、LaTeX 和 Markdown
使用 Handlebars 模板自定义导出内容
可包含高亮内容所在的完整句子，便于理解上下文

使用方法：

安装 Google 学术 PDF 阅读器和本扩展。
在 Google 学术 PDF 阅读器中打开 PDF。
点击工具栏中的“导出批注”，然后选择所需的导出格式。
